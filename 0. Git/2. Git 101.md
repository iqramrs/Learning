/////////////
//GIT DASAR//
/////////////

Create

- git init = untuk inisialisasi git
- git clone = untuk clone (git clone <project>)

Make Changes

- git add <file> = untuk menambahkan file ke staging area
- git add . = untuk menambahkan semua file ke staging area
- git reset <file> = untuk menghapus file/folder dari staging area
- git commit -m "commit message" = untuk membuat commit dengan pesan commit
- git reset --hard

Observe

- git status = untuk melihat status file
- git diff = untuk melihat perbedaan antara file yang sudah di commit dan file yang belum di commit
- git show = untuk melihat commit yang sudah dibuat
- git log = untuk melihat log commit

Sync

-git remote add origin <repository> = untuk menambahkan repository remote

- git remote -v = untuk melihat repository remote
- git push = untuk mengirimkan commit ke repository remote (git push <nama remote repo> <nama branch>)
- git pull = untuk mengambil commit dari repository remote (git pull <nama remote repo> <nama branch>)
- git fetch = untuk mengambil informasi dari repository remote tanpa mengubah local repository

Branch

- git branch = untuk melihat branch yang ada
- git branch <nama branch> = untuk membuat branch baru
- git branch -d <nama branch> = untuk menghapus branch
- git checkout <nama branch> = untuk bergabung dengan branch yang sudah ada
- git merge <nama branch yang ingin di gabungkan> = untuk menggabungkan branch yang sudah ada
- git tag = untuk membuat tag pada commit tertentu
- git tag -a <nama tag> -m "pesan tag" = untuk membuat tag dengan pesan tag
- git tag -d <nama tag> = untuk menghapus tag
