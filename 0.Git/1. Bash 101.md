1.  ls = List dari folder
2.  ls -a = untuk menampilkan semua folder
3.  ls -l = untuk menampilkan semua file dan detail
4.  pwd = print working directory menampilkan path yang sedang digunakan
5.  cd = Change Directory untuk berpindah folder (bisa pencet tab untuk auto complete)
6.  cd .. = untuk Kembali ke folder sebelumnya
7.  mkdir = make a directory
	menggunakan spasi dengan tambahan (\ )
	buat folder didalam folder langsung (mkdir Learning/blabla)
8.  touch = untuk membuat file baru
	buat file didalam folder (touch Learning/blabla.txt)
9.  rm = remove untuk menghapus file
	rm * = untuk menghapus semua file yang ada di dalam folder aktif
10. rm -rf = untuk menghapus folder
	rm -rf * = untuk menghapus semua folder
